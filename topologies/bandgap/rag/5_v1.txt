This PTAT-core bandgap uses a first 5T-OTA loop to enforce equal voltages across a 1x PNP and an 8x PNP (Q1 and the Q2-array with resistor R1), thereby generating a PTAT current. A second 5T-OTA loop then replicates this PTAT current through another PNP (Q3) and resistor (R3) to create a temperature-compensated bandgap voltage, from which the output reference voltage (vref) is resistively divided and a buffered reference current (iref) is provided.
